# 🪷 Funeraria La Orquídea

Sitio web e información institucional de **Funeraria La Orquídea**, en Ibarra, Ecuador. La página presenta sus servicios, planes prepago y canales de atención con una identidad visual elegante, cercana y respetuosa.

> 🤍 “Acompañamos tu despedida con respeto, amor y dignidad.”

## 🌐 Sitio web

La página principal está en [`index.html`](./index.html). Ábrela en un navegador para revisar el sitio localmente. No requiere instalar dependencias ni compilar archivos.

Incluye:

- 🏠 Presentación de la funeraria y su compromiso con las familias de Imbabura.
- 🕊️ Servicios funerarios y atención 24/7.
- 🛡️ Planes prepago Serenidad, Armonía, Legado y Trascendencia.
- 📱 Diseño adaptable a teléfonos, tabletas y computadoras.
- 💬 Enlaces directos para llamar y conversar por WhatsApp.
